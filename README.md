# Лабораторная работа №5
## Разработка механизмов аутентификации и авторизации для WEB-приложений на Flask

### Описание
Простое Flask приложение с механизмами регистрации, авторизации и аутентификации пользователей.

### Требования
- Python 3.7+
- PostgreSQL

### Установка и запуск

#### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

#### 2. Настройка базы данных PostgreSQL

Создайте базу данных в PostgreSQL и выполните SQL скрипт для создания таблиц:

```bash
psql -U your_username -d your_database_name -f create_tables.sql
```

Или выполните содержимое файла `create_tables.sql` через любой PostgreSQL клиент.

#### 3. Настройка подключения к БД

Откройте файл `app.py` и заполните параметры подключения к вашей базе данных:

```python
DB_HOST = 'localhost'          # Адрес сервера БД
DB_PORT = '5432'               # Порт БД
DB_NAME = 'your_database_name' # Название базы данных
DB_USER = 'your_username'      # Имя пользователя БД
DB_PASSWORD = 'your_password'  # Пароль пользователя БД
```

Также рекомендуется изменить секретный ключ:

```python
app.secret_key = 'your-secret-key-here'
```

#### 4. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://127.0.0.1:5000/

### Функционал

- **Регистрация** (`/signup`) - создание нового пользователя
- **Вход** (`/login`) - авторизация существующего пользователя
- **Главная страница** (`/`) - доступна только авторизованным пользователям
- **Выход** (`/logout`) - завершение сессии пользователя

### Безопасность

- Пароли хранятся в зашифрованном виде (используется `werkzeug.security`)
- Неавторизованные пользователи перенаправляются на страницу входа
- Используется flask-login для управления сессиями
